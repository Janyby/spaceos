Select tab…

            
View — live page frame via CDP (Page.captureScreenshot, ~1.5 s), no mimicry and no security policy bypass. Clicks inside the page are not forwarded by this contract — interactivity happens in the Chromium window via «Show in Chromium» or through the built-in iframe surface (`#bframe`) when loaded. URL navigation, refresh, tab create/close run through the existing browser-provider via Core Policy (`POST /providers/browser/actions`). Native embedded browser (`C# WinForms + WebView2`) requires `.NET SDK` + `WebView2 SDK loader` (not installed in this environment); current vertical slice uses the iframe surface with the same Provider contracts.
